# 自訂 Codex Pets

把每一隻 Codex 寵物完整資料夾放在這裡，例如：

```text
pet/
  my-pet/
    pet.json
    spritesheet.webp
```

支援 Codex Pets v1（8×9）與 v2（8×11）圖集。放入或更新寵物後，請在 Chrome 的擴充功能頁重新載入本擴充功能；寵物會自動出現在設定面板的 Pet 選單中。

後台「資料備份」的兩種匯出都會包含 Pet 選擇、位置、顯示狀態、快捷連結，以及目前與所有自訂 Pet 的名稱、描述、動畫設定與圖集。其他未選取的內建 Pet 隨擴充功能提供，不重複嵌入圖集。JSON 備份上限為 10 MB。

匯入新版備份會將圖集保存於擴充功能本機儲存區，無須再手動複製寵物資料夾；重新整理 Halo 頁面後即可使用。舊版備份仍可匯入，且不會移除本機已還原的圖集。同 ID 的備份 Pet 優先於資料夾版本。
