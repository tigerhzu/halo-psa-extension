# 自訂 Codex Pets

也可從後台「Pet 寵物」直接匯入：

1. 按「選擇 Pet 資料夾」，直接選擇單一寵物的整個資料夾，例如 `claude-crab`。
2. 系統自動讀取最外層的 `pet.json`，以及 `spritesheetPath` 指定的 PNG／WebP 圖集（預設為 `spritesheet.webp`，也支援子資料夾路徑）。不需分別選取檔案。
3. 按「匯入 Pet」，再重新整理 Halo 頁面。預設會設為目前 Pet 並顯示，也可取消勾選。`pet.json` 若未提供 `id`，會使用符合命名規則的資料夾名稱。

這種方式將 Pet 保存於瀏覽器的擴充功能儲存區，不需要搬動原始檔案。相同 ID 會更新已匯入的 Pet；其他設定與其他 Pet 會保留。單張圖集上限為 7 MB，且匯入後的整份備份須在 10 MB 以內。

把每一隻 Codex 寵物完整資料夾放在這裡，例如：

```text
pet/
  my-pet/
    pet.json
    spritesheet.webp
```

支援 Codex Pets v1（8×9）與 v2（8×11）圖集。放入或更新寵物後，請在 Chrome 的擴充功能頁重新載入本擴充功能；寵物會自動出現在設定面板的 Pet 選單中。

後台「資料備份」的兩種匯出都會包含 Pet 選擇、位置、顯示狀態、快捷連結，以及目前與所有自訂 Pet 的名稱、描述、動畫設定與圖集。其他未選取的內建 Pet 隨擴充功能提供，不重複嵌入圖集。JSON 備份上限為 10 MB。

匯入新版備份會將圖集保存於擴充功能本機儲存區，無須再手動複製寵物資料夾；重新整理 Halo 頁面後即可使用。舊版備份仍可匯入，且不會移除本機已還原的圖集。同 ID 的備份 Pet 優先於資料夾版本。
