剪貼後台 使用說明

取得安裝檔與安裝

向 IT／工具管理者取得 Clarity-Setup.exe，適用 Windows x64。

  1. 連按兩下 Clarity-Setup.exe，依畫面完成安裝。

    缺少 WebView2 時，安裝器可能需連網補齊；安裝受限請聯絡 IT。

  2. 從開始功能表開啟「剪貼後台」。
  3. 複製一段文字，按 Alt + Z。

    在「最近複製」看到文字，表示已開始記錄。

剪貼後台

依實際介面重繪；圖片與資料為示範內容。

  • 左側：切換最近複製、已釘選、常用片段、資料夾，以及內容類型／時間篩選。
  • 中間：選取歷史項目，右側查看完整內容；點圖片可放大。
  • 右下：「複製內容」放回剪貼簿，再到原程式貼上；「保存到」可收藏至資料夾或常用片段。
  • 左下設定：調整快捷鍵、歷史保留時間與隱私。

找回之前複製的內容

  1. 確認程式執行中，照常用 Ctrl + C 複製。
  2. 按 Alt + Z，輸入關鍵字搜尋。
  3. 選項目查看預覽，按「複製內容」。

    也可連按兩下項目，或在清單選取後按 Enter。

  4. 回到原程式，點輸入位置，按 Ctrl + V。
用途操作結果
這筆歷史不要過期選取歷史項目 → 按釘選圖示，或 Ctrl + P。出現在「已釘選」，不受一般歷史到期清理影響。
依工作／客戶分類「收藏資料夾」旁按 ＋ 建立資料夾，再把項目拖入；也可由預覽的保存選單選目的地。保存獨立快照，方便日後在資料夾取用。
常常要貼同一段話「常用片段」旁按 ＋，或 Ctrl + N → 填標題與內容 → 儲存。建立個人片段，可編輯、搜尋與重複複製。
歷史裡有好用的回覆選歷史項目 → 保存選單 →「常用片段」。將現有內容保存成日後取用的片段。
快捷鍵與設定
  • Alt + Z：顯示／隱藏視窗。
  • Ctrl + K 或 Ctrl + F：搜尋。
  • Ctrl + N：新增片段。
  • Ctrl + ,：開啟設定。
  • 儲存設定：保留 7、14、30 天或永久；釘選與收藏不受一般到期清理影響。
  • 隱私設定：排除不想記錄的程式；已保存的敏感內容須自行刪除。
按視窗 × 只會隱藏，仍繼續記錄。要停止，請從 Windows 右下角通知區的程式選單結束 Clarity。

更新與備份

更新

向 IT 取得新版 Clarity-Setup.exe，依提示結束程式並安裝。

備份

  1. 從 Windows 通知區完整結束 Clarity。

    只按視窗 × 不算結束。

  2. 將下列位置貼到檔案總管網址列。

    %APPDATA%\com.tigerhzu.clarityclipboard\

  3. 複製整個資料夾到備份位置。

    包含資料庫、設定與 images。還原前也要結束程式，不確定時請 IT 協助。

歷史與收藏保存在本機，不會自動同步。備份含剪貼內容，請妥善保管。

常見問題

找不到剛才複製的內容。

確認複製當時程式正在執行，清除搜尋與篩選後，用一般純文字測試。隱私過濾、排除程式或保留期限可能影響記錄。

Alt + Z 沒反應。

先從開始功能表開啟程式，再檢查設定中的快捷鍵；與其他程式衝突時可修改。

按「複製內容」後，沒有貼到其他程式。

回到目標程式，點輸入位置，再按 Ctrl + V。

關閉視窗後仍在記錄。

× 只隱藏視窗。要停止，請從通知區的程式選單結束 Clarity。
