Wiki 使用說明

取得安裝檔與安裝

向 IT／工具管理者取得公司提供的 Wiki 輔助 安裝 ZIP，使用 Chrome 或 Edge 安裝。

公司 Wiki 網域已預設，直接安裝即可，不需要填網址或執行設定指令。
  1. ZIP 按右鍵 →「解壓縮全部」。

    放到固定資料夾，安裝後不要移動或刪除。

  2. 開啟擴充功能管理頁。

    Chrome：網址列輸入 chrome://extensions；Edge：輸入 edge://extensions，按 Enter。

  3. 開啟「開發人員模式」→「載入未封裝項目」。

    部分版本稱「載入解壓縮檔」。選含 manifest.json 的資料夾，不是 ZIP 檔。

  4. 回到公司 Wiki，重新整理頁面。

    安裝後可由 Wiki 頂部「工作台」開啟功能與設定。

安裝畫面示意

首頁與工作台

頂部「工作台」集中常用工具；「照片」開啟圖片資料庫，「拓譜」查看頁面連結，齒輪進入設定。

Pet 與客戶目錄

點左下角橘色 Pet，開啟客戶目錄；搜尋並點選客戶，即可跳轉到客戶頁面。

Pet 隱藏時，也可從「工作台 → 客戶目錄」開啟。圖中客戶為示範資料。

工作台

點「工作台」，或按 Ctrl + Shift + K，搜尋並選取功能。

文章模板與 AI 排版需進入編輯頁才可使用。側欄外觀可調整顏色；隱藏 Pet 後仍能使用工作台。

圖片資料庫

點頂部「照片」，或工作台 →「圖片資料庫」。

  • 查看圖片：確認資料夾路徑，按「載入」，一併查看子資料夾圖片。
  • 改檔名：點縮圖下方的檔名修改。
  • 刪除：單張按「刪除」；多張先勾選，再按「刪除已選取」。

重新命名與刪除會操作 Wiki 真實圖片資產，先確認其他文章是否仍使用它們。

頁面拓譜

點頂部「拓譜」，或工作台 →「頁面拓譜」，查看目前文章連到哪些頁面。

  • 展開／前往：左鍵點連結節點展開或收合；右鍵前往該頁面。
  • 調整畫面：用「−／＋」縮放、「適合視窗」置中，也可切換全螢幕。

原始碼與視覺編輯

開啟文章編輯頁，在右上角切換模式。

原始碼

左側修改 Markdown 文字與格式符號，右側同步查看排版預覽。

視覺編輯

直接點文章輸入，反白文字後設定粗體、標記、對齊或更多格式。

  • 圖片：貼上或拖入後等待上傳完成；右鍵點圖片可調整尺寸與樣式。單張上限 5 MB。
  • AI 排版：點頂部「AI 排版」，檢查結果後套用；未選取文字時會處理全文。
  • 儲存：完成後按原生 SAVE，確認顯示 SAVED。遇到同步錯誤先保留內容，不要直接重新整理。

文章模板

在編輯頁點頂部「模板」，或工作台 →「文章模板」。

  • 套用：搜尋或選分類 →「預覽」→ 關閉預覽 →「插入」，再依本次需求修改內容。
  • 管理：按「＋」新增模板，或「收藏目前文章為模板」；可編輯、複製與匯出／匯入。
  • 取代全文：會替換目前整篇內容，確認要重做時才使用。

模板插入或 AI 套用後，仍需 SAVE。圖中的客戶與文章內容為示範資料。

設定、更新與備份

AI 設定（選用）

頂部齒輪／工作台 → 設定 → AI 助手。需要啟用時，依 IT 提供的服務資料設定；連線異常請聯絡 IT。

AI 會將待處理內容傳至指定服務。一般編輯與模板功能不需要 AI。

備份與還原

頂部齒輪／工作台 →「設定」，找到備份區。

  • 一般備份：按「下載備份檔」，匯出不含 API 金鑰的資料。
  • 進階備份：包含 API 金鑰，備份檔請妥善保管。
  • 還原：按「選擇備份檔」，選取先前匯出的檔案，依畫面提示還原。

更新

  1. 先儲存工作，在設定匯出不含 API Key 的備份。
  2. 向 IT 取得新版 Wiki 輔助 安裝包，更新原本的安裝資料夾。

    使用公司提供的預設版本，不需要另填 Wiki 網域。

  3. 擴充功能管理頁 →「重新載入」，再重新整理網站。

    若換了安裝資料夾，可能需匯入備份並重新設定 AI。

設定備份不包含文章或未儲存草稿。換電腦時需匯入設定；含金鑰的備份請妥善保管。
