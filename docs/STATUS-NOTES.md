# 狀態文字自動帶入

目前安裝包 `output/halo-psa-extension-1.1.4.3` 以使用者實際掛載的 1.1.4 資料夾為基底，加入狀態文字與設定入口修正。未包含主線 1.1.7 的 Halo API 功能。

1.1.4.3 將工作台「設定」改為原生連結，初始化時快取擴充功能設定頁位址，不再等待背景訊息。只對既有四個 Halo 網域開放該設定 HTML 的導覽。內建瀏覽器已驗證背景訊息失效及舊連線失效時仍能開啟設定，修改文字後重新整理仍保留。正式 Edge 載入驗證尚未執行。

`python scripts/build-status-notes-release.py` 從此獨立安裝包產生可分享的 ZIP，移除私人 AI 主機權限，附安裝說明、來源摘要與 SHA256。打包時檢查敏感資料標記，實際解壓後檢查資源並執行狀態及設定入口測試。

1.1.4.2 修正 1.1.4.1 未能辨識實際新動作的問題：Halo 的 `.newaction` 祖先同樣是 `.action-history-item`，新增中的草稿使用 `data-id="-1"` 與 `isadding`。舊版將所有歷史容器排除，導致空白與 `$SERVICESTATUSNOTE` 都不會填入；新版只放行這個明確的未儲存標記，仍排除已保存紀錄。已在正式頁面確認祖先結構，並以該結構重現舊版失敗、驗證新版帶入成功。

在擴充功能設定頁選「狀態自動帶入」，可開關功能或修改八種文字；輸入後自動儲存，下一次開啟動作生效。單一欄位留白會停用該狀態。「恢復全部預設文字」會恢復八筆文字並重新啟用。

| 狀態／動作 | 預設文字 |
| --- | --- |
| Open / Opened | 案件進入受理階段。 |
| In Progress | 案件列為處理中。 |
| Awaiting Customer Reply | 案件列為等待客戶回覆。 |
| Pending | 案件列為暫緩處理。 |
| On Hold | 案件列為暫停處理。 |
| Postponed | 案件列為延後處理。 |
| Final Check with Customer/Sales | 案件進入客戶 / 業務最終確認階段。 |
| Closed | 案件列為已結案狀態。 |

Closed 也辨識 Resolved Ticket／Resolve Ticket；Open 辨識 Reopen／Re-open。其他自訂動作不會猜測對應狀態。

只處理目前案件的新狀態動作表單：空白或純 `$SERVICESTATUSNOTE` 佔位文字可以帶入，手動文字、圖片、表格、寄信表單及歷史動作不會覆寫。重複掃描不會重複插入；手動清空也不會強制填回。此功能不自行送出表單。原本 1.1.4 的快速改狀態前置流程維持原行為，前置儲存前會等待文字同步。

設定保存在既有 `hpx_settings.statusNotes`，沿用一般備份／匯入。文字以純文字轉義後寫入，支援多行，不會當作 HTML 執行。

## 驗證

- 單元測試：八種狀態、別名、未知動作、佔位文字、手動內容與媒體保護、開關／留白、儲存延遲、切換案件、編輯器失效、接續流程等待與中止。
- 內建瀏覽器：查看正式 Halo 的新狀態表單結構與佔位文字，未點 Save。以同樣的 DOM 結構在本機測試頁驗證實作與設定持久保存。
- 本機瀏覽器頁：`node tests/preview-server.js`，開啟 `http://127.0.0.1:4173/tests/status-notes-browser-test.html`。
- 本機模擬的 Froala bridge 驗證寫入與模型同步；正式 Edge 擴充功能重新載入後的實際送出仍需使用者日常操作確認。

## 開發基底

主線中保留新增功能與測試，沒有移除既有 API 模組。本次交付與掛載更新只使用 1.1.4 基底的獨立安裝包。
`scripts/integrate-status-notes.py <root> [version]` 可在既有副本加上整合掛點；四個新增模組需從主線複製。它不會將 1.1.7 的其他功能加入舊版。
