# 更新紀錄

## 公開發佈整理 · 1.1.2

- 重寫 README、技術架構、開發與發佈文件，加入品牌 logo、GitHub 主視覺及系列專案連結。
- 將公開來源中的部署專用 AI 主機改成示例網域。自架 Ornith 以本機設定腳本精準授權單一 HTTPS 主機，背景服務驗證設定的 origin。

## 1.1.2 · 2026-09-05

- 桌面版原生時／分／秒、計時器及快捷調整放在同一列；窄視窗自然換行。移除重複的可見時間摘要。
- 工作台、設定、編輯器與閱讀器按鈕採實色填滿、清楚邊框及圓角；白色自訂主題保留操作邊界。
- 設定頁以淡藍紫漸層與不透明白色卡片取代背景圖片與前景模糊。
- 左側導覽列跟隨主題色，中間 Team／人員清單保持淺灰白底。
- 工時播報僅回應使用者操作，避免原生計時器同步造成持續播報。
