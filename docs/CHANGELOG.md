# 更新紀錄

## 1.1.10 · 2026-11-17

- 將頁面功能拆成獨立的閒置啟動任務，保留即時訊息／狀態監聽，並共用啟動 timeout 預算，讓 Halo 有機會先完成畫面與輸入處理。
- 主題偵測優先限縮在 Halo 原生導覽根節點，快取單次量測結果；無關工單更新與主題自身的標記不再造成全頁版面掃描。
- 寄信偵測合併 CC 查詢、移除無效的通用候選搜尋、快取標題查詢，忽略寵物、工具列與編輯器輸入等無關變動；保留 CC 顯示切換與動態 Action 白名單判斷。
- Time Taken 改用增量標籤索引，新增、文字／aria-label／title 更新、欄位替換及移除均維持正確掛載；不再因每批工單列更新而遍歷整頁標籤。
- 簡單模式合併渲染期間的掃描，背景分頁延後處理，支援 Navigation API 的瀏覽器移除固定網址輪詢；原生導覽列搜尋限縮範圍，先比對文字再讀取版面。
- 編輯器的子樹候選查詢合併成一次；避免輸入／貼上內容觸發額外工具列偵測，並保留不合法自訂 selector 的回退處理。
- 本次公開版包含 1.1.8／1.1.9 的玻璃外觀、狀態備註、Pet 資料夾匯入與備份更新。新增 Chromium 效能回歸與可重跑的三組比較腳本，詳見 `docs/PERFORMANCE.md`。

## 1.1.9 · 2026-11-13

- 新安裝預設：輕透、#FF7A1A、海洋、強度 42%、透明度 45%（儲存值 opacity 為 55）。
- 匯入任何版本的設定備份時，不採用檔案中的主題、配色、透明度與背景，統一套用上述橘色透明玻璃預設；功能、聯絡人與 Pet 設定照常還原，金鑰沿用既有匯入規則。
- 後台新增「Pet 寵物」，直接選擇整個 Pet 資料夾，一次讀取 pet.json 與指定圖集，支援 v1／v2、PNG／WebP 與子資料夾圖集。
- 一般及完整備份包含 Pet 選擇、位置、顯示狀態、快捷連結，以及目前與自訂 Pet 的描述、動畫設定與圖集；匯入備份可直接還原，並相容舊版設定檔。
- 匯入同 ID 的 Pet 會更新該 Pet；損毀圖集或超出大小／儲存限制時顯示錯誤，保留原設定。整份備份上限為 10 MB。

## 1.1.8 · 2026-11-13

- 狀態動作開啟時自動帶入備註；修正設定入口，並節流全頁觀察器以減輕 Halo 大量重新渲染時的負擔。
- 統一左側搜尋框的玻璃底層、圓角與焦點邊框，消除原生深色底露出的邊角；案件篩選按鈕同步調整邊框與內距。
- 載入工單時延續背景渲染，避免大片純色遮罩；案件篩選選單與 Category／我的最愛視窗改為玻璃面板、浮起的分類列及主題色選取提示。
- 「輕透」主題改為玻璃質感：左下角控制列、提示訊息與浮層採半透明加模糊；工具列按鈕去掉外框，AI 動作合併為一組分段控制。選單、浮層與 AI 草稿視窗維持近乎不透明，避免底下文字穿透。「原生配色」不受影響。
- 「外觀與主題色」面板新增背景渲染：八種預設風格、渲染強度與透明度。新安裝預設為「輕透」、橘色 #FF7A1A、海洋背景、渲染強度 42%、透明度 45%；既有使用者已保存的設定會保留，選「無」可關閉背景渲染。
- 渲染背景套用在 Halo 淺色主題的工單清單與工單詳情頁；其他頁面與 Halo 深色主題維持原樣。設定頁、獨立編輯器與閱讀器視窗的外觀未變。
- 系統開啟「減少透明度」時自動改回不透明介面並停用渲染背景。
- 「輕透」主題下，左側導覽列的 Timesheets 與 Team 圖示改放在玻璃方塊上，目前所在的 Team 加上外框；淺色主題選用背景渲染時，Team 清單與工單共用連續背景，每位人員各自呈現懸浮玻璃卡片，選取列以淡主題色與細框標示。

## 1.1.7 · 2026-11-05

自 1.1.2 起累積的更新：

- 工單頁新增快速改狀態，可依租戶的原生流程接續 In Progress、Final Check 與結案動作。
- 後台可選擇啟用 Halo API，直接開案、改狀態與結案。原生 API Key 使用 `X-Halo-Api-Key`，另支援 Bearer 和公司閘道的 `X-API-Key`。
- Azure AI 增加 Thinking 模式設定、請求逾時處理與回應時間明細，並調整草稿輸出驗證。
- 更新工時調整、富文字處理及操作圖解。安裝包附 Halo API 設定說明與 SHA-256 校驗檔可供下載。
