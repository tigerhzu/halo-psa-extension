HaloPSA Writing Helper 設定

支援 Azure OpenAI 與 Gemini；連線資料只儲存在目前瀏覽器。

外觀 Appearance

即時生效、不需重新整理、不開新分頁。只套用在本擴充自己的 UI，不影響 HaloPSA 介面。

如何取得免費的 Gemini API Key

  1. 前往 Google AI Studio → API Keys（aistudio.google.com/apikey）。
  2. 用 Google 帳號登入，點選 「Create API key」。
  3. 可選「Create API key in new project」自動建立專案，或選現有專案。
  4. 複製產生的金鑰（格式類似 AIza…），貼到下方欄位並儲存。

透過 AI Studio 取得的金鑰預設使用 免費額度（free tier）； 只要不在 Google Cloud 啟用付費結算，就不會產生費用。免費額度有每分鐘 / 每日請求上限， 個人撰寫工單的用量通常綽綽有餘。

聯絡人名單（寄信 CC 快速加入）

在 HaloPSA 寄信視窗（Email / Reply / Send Email / Email Customer）的「聯絡人」工具列， 可一鍵把整個群組或單一成員加入 CC（已存在者不重複、不覆蓋其他人）。 新增群組（例如 主管、同事、專案經理）後， 寄信視窗會自動多出對應按鈕 —— 不需要改任何程式。
