Halo API 連線

設定完成後，工單的「快速改狀態」會直接呼叫 API 儲存。此處設定需按下儲存才會生效。

Halo 原生金鑰使用 X-Halo-Api-Key，與公司閘道的 X-API-Key 不同。請依憑證提供方確認 API 位址與方式；短效 Access Token 過期後需更新。

請使用租戶實際的結案動作與狀態 ID。結案會執行這個 Action，Halo 中的通知與工作流程依該動作設定執行。

Halo 憑證只存於此瀏覽器的擴充功能本機儲存區，與 AI 金鑰分開；一般與完整設定備份都不包含此連線，換電腦需重新設定。
